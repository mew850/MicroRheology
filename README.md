# MicroRheology Model for Battery Slurry

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

> 基于微观机制的锂离子电池电极浆料流变模型

本项目实现了一个基于微观机制的流变模型，用于计算和预测锂离子电池电极浆料的黏度、势能及其他关键参数。模型考虑了范德华力、静电排斥力、Born排斥力等胶体相互作用，能够为电池浆料的配方设计和涂布工艺优化提供理论指导。

## 📚 背景

锂离子电池电极浆料的流变性质直接影响涂布工艺、电极结构和电池性能。传统的试错法耗时且成本高。本项目基于文献［1］中的微观流变模型，使用 Python 实现了该模型的数值计算，帮助研究人员快速评估浆料流变特性。

## ⚙️ 功能特性

- **DLVO 势能计算**：计算炭黑（CB）团聚体间的范德华势、Born 排斥势和静电势
- **微观流变特性分析**：计算势阱深度（Uc）、势垒高度、最大作用力（Fc）以及刚度系数（k₀）
- **参数可配置**：支持通过类参数和外部配置文件灵活调整材料参数和计算精度
- **结果可视化**：提供 Jupyter Notebook（`test01.ipynb`）用于数据分析和图表生成
